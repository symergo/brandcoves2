GiftCoves bol importer

Production is https://giftcoves.com. Staging is https://staging.giftcoves.com. Any other address has to be allowed once, and Chrome will ask.

Mint one with php artisan bc:api-token. It needs the editorial.write ability and nothing more — a key that can import products does not need to be able to publish anything. Stored on this machine only, never synced.

A bol page normally says which market it is: /nl/nl/, /be/nl/, /be/fr/. This is the fallback for the ones that do not, and the popup always shows which market is about to be used.
